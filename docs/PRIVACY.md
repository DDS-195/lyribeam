# 隐私与本地数据

## 手机端

手机助手读取当前音乐会话，并从合格音乐通知或用户批准的主动接口取得歌曲信息。仅选择音乐通知参与歌词链路。传输内容包括歌曲、歌手、专辑、时长、播放状态、可信进度、来源/会话身份，以及来源主动提供时的完整歌词。

手机应用不申请互联网或录音权限。歌曲快照通过已配对蓝牙连接发送到电脑；工具不转发手机音频。

## 电脑端

开启联网匹配时，桌面应用会把当前查询所需的歌名、歌手、专辑、时长或有效平台编号发送给现有歌词服务。关闭联网匹配时，可继续使用授权提供的歌词与本地可验证缓存。

本地数据目录可能保存歌词正文、最近歌曲状态、歌曲偏移、外观设置和查询诊断。请勿将这些文件作为问题附件或提交到源码仓库；报告问题时可仅提供必要歌曲元信息和已去除设备信息的错误原因。

## 此仓库的内容边界

上传内容是源码、合成测试、构建脚本、当前图标和使用文档。未包含原开发签名、账户凭据、设备序列号、配对地址、真实缓存、运行日志或个人手机/桌面截图。测试中的示例歌曲字段用于匹配逻辑检查，不构成听歌记录或歌词数据库。

构建脚本在本机生成的调试密钥、构建输出和测试结果由 `.gitignore` 排除。正式发布签名应单独保管，不能提交或放入GitHub下载附件。
