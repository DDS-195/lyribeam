# 数据链路与兼容范围

## 两端职责

Android 负责选择当前播放来源、读取整份歌曲快照、计算可信进度并通过已配对蓝牙连接发送。Windows 负责接收、校准进度、取得并校验歌词、缓存及绘制桌面窗口。

```mermaid
flowchart LR
    P[手机音乐播放器] --> A[Android 助手]
    A -->|歌曲信息、进度、可选 LRC| B[蓝牙 RFCOMM]
    B --> W[Windows 接收与进度时钟]
    W --> Q[可信提供歌词、缓存或网络查询]
    Q --> V[版本与时间轴校验]
    V --> L[桌面当前句与下一句]
```

应用不转发手机音频，也不向手机发送播放控制命令。

## 手机输入

1. `media-session`：Android 标准媒体会话。包名无需位于固定平台名单中，字段和能力决定可用程度。
2. `notification`：合格音乐通知的保守回退；不能从通知确认时钟时明确为仅歌曲信息，不伪造进度。
3. `integration`：可选开发者主动接入。默认关闭，用户逐个批准来源，核验真实调用方身份，完整歌词与当前会话和歌曲绑定。

各来源只整份选择，不把一个播放器的歌词与另一个播放器的时钟混合。快照保留真实包名、原始媒体编号、歌名、全部歌手、专辑、时长、进度能力和会话/歌曲身份。

## 歌词取得与校验

授权且绑定当前歌曲的完整 LRC → 私有缓存 → 严格验证的共享缓存 → 原平台优先与多来源网络检索。

酷狗、QQ和网易云会在对应平台内解释有效歌曲编号；QQ的数字编号和MID分别处理。其他播放器的本地编号保持不透明，不会仅凭数字就作为酷狗编号。没有有效平台编号时仍可使用歌曲元信息检索。

来源适配器保留歌词来源、候选信息和校验依据。原生编号确认与普通搜索依据分级：只有完整、独立核对的原生录音可以使用已验证发行标签兼容规则；普通搜索不凭同名和同歌手放宽明确版本冲突。

共用规则检查完整歌手、标题/语种/现场等版本标记、专辑、时长、歌词头部及时间轴。切歌取消旧请求；失败重试不会用空结果覆盖仍可用歌词。

现有网络来源包含酷狗、QQ音乐、网易云和LRCLIB。接口可能改变，也可能没有收录对应版本；通过歌曲读取不等于必然能找到同步歌词。

## 缓存与诊断

私有缓存保留来源及歌曲依据并在读取时重验。共享缓存要求正文具有真实可核对的歌名、歌手、专辑和匹配时长；跨播放器重用时重新验证，不传播原生编号的专辑放宽权限。

本地诊断保留有上限的查询状态、候选头部及拒绝原因，不记录完整歌词正文或接口访问密钥。诊断、缓存、偏移、运行状态及所有验证产物均排除在源码提交外。

## 标识兼容

LyriBeam 是项目名称；现有桌面程序集 `LyricBridge`、Android 包名 `com.local.lyricbridge` 和协议标识继续保留。不要为单纯更名修改应用包名、蓝牙服务标识或数据键。
